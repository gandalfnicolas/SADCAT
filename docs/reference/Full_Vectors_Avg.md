# Average Word embeddings for expanded dictionaries

Average word embeddings for expanded dictionaries

## Usage

``` r
Full_Vectors_Avg
```

## Format

A data frame with 56 rows. Key column groups:

- `Dictionary`: Name of the dictionary the embeddings represent

- `ft.*`: Fasttext word embedding dimensions (Common Crawl)

- `Glove.*`: GloVe word embedding dimensions (Common Crawl 840B)

- `w2v.*`: Word2vec embedding dimensions (Google News)

- `USE.*`: Universal Sentence Encoder embedding dimensions
