# Tokenize character input with stable row-based docnames

Tokenize character input with stable row-based docnames

## Usage

``` r
.tokenize_quanteda_text(x, prefix = "doc", ...)
```

## Arguments

- x:

  A character vector

- prefix:

  Prefix for generated docnames

- ...:

  Passed to
  [`quanteda::tokens()`](https://quanteda.io/reference/tokens.html)

## Value

A quanteda tokens object
