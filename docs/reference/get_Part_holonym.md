# Wordnet part holonym retriever

Gets part holonyms for a term's synset

## Usage

``` r
get_Part_holonym(synsets, Syns = T)
```

## Arguments

- synsets:

  synsets to obtain part holonyms for

- Syns:

  Return the synsets? Defaults to TRUE. If FALSE, returns the various
  words that make up the synsets.

## Value

part holonyms of words
