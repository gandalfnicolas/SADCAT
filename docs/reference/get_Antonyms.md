# Wordnet antonym retriever

Gets antonyms for nouns or adjectives of a term's synset

## Usage

``` r
get_Antonyms(synsets, Syns = T)
```

## Arguments

- synsets:

  synsets to obtain antonyms for

- Syns:

  Return the synsets? Defaults to TRUE. If FALSE, returns the various
  words that make up the synsets.

## Value

antonym expansion
